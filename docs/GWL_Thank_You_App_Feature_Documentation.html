SECTION A - Admin Panel Features

1. Dashboard Home

The Dashboard is the app landing page. It gives merchants a quick performance snapshot and a direct path to Shopify checkout customization.

Feature Description
Performance Snapshot Displays Total clicks, Today, and Last 7 days values from tracked thank-you page interactions.
Recent Activity Shows the latest five click events with date, event type, and the clicked item or CTA text.
Top Signal Aside panel highlights the most frequent click event type from the last 7 days.
View Analytics Button Primary action that navigates to the app Analytics page.
NEWCustomize Checkout CTA Opens Shopify Admin checkout settings: https://admin.shopify.com/store/gwl-apps-demo/settings/checkout.

2. Analytics

The Analytics page provides click reporting across all thank-you page blocks that call the shared tracking helper.

Feature Description
Total Clicks Counts all tracked click records for the authenticated shop.
Today Clicks Counts records created since the start of the current day.
Clicks by Type Groups events such as Subscription Click, Loyalty Click, Referral Click, Video Click, FAQ Click, and Recommended Product Click.
Recent Clicks Table Lists up to 50 recent clicks with date, type, and an available link to the clicked CTA or product.

3. Click Tracking API

Item Description
Endpoint /api/analytics-click
Stored Fields Shop, event type, order ID, order number, CTA text, CTA link, item ID, item title, item URL, source, raw payload, and created date.
CORS Support Supports extension-side POST and OPTIONS requests with permissive CORS headers.
Shop Validation Requests must include a shop domain before a click record is saved.

SECTION B - Checkout Customization and Extension Blocks

All customer-facing modules are Shopify Checkout UI Extensions targeting purchase.thank-you.block.render. Merchants add them from Shopify Admin checkout customization; no theme code editing is required.

4. Available Thank-You Page Blocks

Block Name Purpose Customer Interaction
Thank You - Subscription Section Promotes subscription, membership, or repeat-purchase offers. CTA button opens merchant-configured URL and tracks subscription_click.
Thank You - Loyalty Section Promotes a loyalty or rewards program after purchase. CTA button opens merchant-configured URL and tracks loyalty_click.
Thank You - Referral Section Promotes referral incentives such as give/get reward programs. CTA button opens merchant-configured URL and tracks referral_click.
Thank You - Discount Section Displays a discount code for the customer's next purchase. Customer views the configured discount code on the thank-you page.
Thank You - FAQ Section Displays up to 10 frequently asked questions and answers. Opening an FAQ answer tracks faq_click.
Thank You - Video Section Displays a video thumbnail and heading linked to a hosted video. Thumbnail click opens video URL and tracks video_click.
Thank You - Upsell Section Shows product recommendations based on purchased product metafields. Product image/link click opens product URL and tracks recommended_product_click.

5. Checkout Customization Setup

Step Admin Action
1. Open App Open the GWL Thank You App in Shopify Admin.
2. Use CTA Click Customize checkout from the app home page.
3. Select Checkout Profile Choose the active checkout profile and open the checkout editor.
4. Navigate to Thank-You Page Switch the editor view to the thank-you page area.
5. Add App Blocks Add one or more GWL Thank You blocks from the Apps section.
6. Configure Settings Enter headings, descriptions, CTA text, CTA URLs, discount code, FAQs, or video URLs as needed.
7. Save Save the checkout customization and place a test order for validation.

6. Block Settings Reference

Block Settings Validation
Subscription Heading 1, Heading 2, CTA Text, CTA Link 60, 120, 24, and 2048 character maximums.
Loyalty Heading, Description, CTA Text, CTA Link 60, 160, 24, and 2048 character maximums.
Referral Heading, Description, CTA Text, CTA Link 60, 160, 24, and 2048 character maximums.
Discount Discount Code 32 character maximum.
FAQ FAQ Question 1-10 and FAQ Answer 1-10 Questions: 80 characters. Answers: 240 characters.
Video Video Heading, Video URL, Video Thumbnail Image 60, 2048, and 2048 character maximums.
Upsell No merchant-facing extension settings. Recommendations come from product metafields.

SECTION C - Customer-Side Experiences

7. Subscription CTA Flow

Step Customer Experience
1. Order Complete Customer lands on the thank-you page after checkout.
2. Offer Visible The configured subscription heading, description, and CTA are displayed.
3. CTA Click Customer clicks the CTA and opens the configured subscription URL in a new tab.
4. Tracking The app records event type subscription_click with CTA and order context.

8. Loyalty and Referral Flow

Step Customer Experience
1. Block Displayed Customer sees a loyalty or referral promotion on the thank-you page.
2. CTA Click Customer clicks Join Now, Refer a Friend, or merchant-configured CTA text.
3. Destination Configured CTA URL opens in a new tab.
4. Tracking The app records loyalty_click or referral_click.

9. Discount Code Flow

Step Customer Experience
1. Block Displayed The customer sees a "Discount code" card on the thank-you page.
2. Code Visible The configured code is displayed in a bordered code area.
3. Fallback If no code is configured, the block displays "No code available".

10. FAQ Flow

Step Customer Experience
1. FAQ List Configured FAQ questions appear as expandable buttons.
2. Open Answer Customer opens a question to reveal the answer.
3. Tracking Opening a closed FAQ records faq_click with the question text.
4. Empty State If no valid FAQ pairs are configured, the block shows "No FAQs configured".

11. Video Flow

Step Customer Experience
1. Block Displayed Customer sees a heading, helper text, and 16:9 thumbnail image.
2. Thumbnail Click Video URL opens in a new tab.
3. Tracking The app records video_click with the heading and URL.
4. Required Settings The block renders only when both Video URL and Thumbnail Image are configured.

12. Recommended Products Flow

Step Customer Experience / System Behavior
1. Order Context Read The block reads order ID, order number, shop domain, and storefront URL from checkout context.
2. API Request It calls /api/recommendations with order data.
3. Metafield Lookup The API reads each purchased product's custom.recommended_products product reference metafield.
4. Recommendations Displayed Up to 8 recommended products are shown with image, title, and product link.
5. Product Click Clicking a product records recommended_product_click.

SECTION D - QA Test Script

13. Admin Setup QA

Step Expected Result
Open the app home page. Dashboard loads with heading "Thank You Dynamic Solutions".
Verify Performance Snapshot. Total clicks, Today, and Last 7 days cards are visible.
Click View analytics. Analytics page opens inside the embedded app.
Return home and click Customize checkout. Shopify Admin checkout settings opens in a new tab.
Add each Thank You app block in checkout customization. Blocks can be added without theme code changes.
Save checkout customization. Shopify saves the configured thank-you page layout.

14. Customer Flow QA

Step Expected Result
Place a test order. Customer reaches the thank-you page after checkout.
Verify configured blocks. Subscription, loyalty, referral, discount, FAQ, video, and upsell blocks appear as configured.
Click subscription, loyalty, referral, and video CTAs. Each opens the configured URL in a new tab.
Open an FAQ item. Answer expands and the FAQ interaction is tracked.
Click a recommended product. Product page opens and click is tracked.
Open app Analytics. Click totals and click types update with the tested interactions.
Open app home page. Recent Activity shows the latest tracked click events.

15. Recommendation Metafield QA

Scenario Expected Result
Purchased product has recommended product references. Recommendations display on the thank-you page.
Recommended product is also in the purchased product list. Duplicate purchased product is excluded from recommendations.
No recommendation metafields are configured. Block displays "No recommendations found".
Order ID is unavailable. Block displays an order ID error state.

Appendix A - Event Type Reference

Event Type Triggered By Primary Data Captured
subscription_click Subscription CTA button CTA text, CTA link, order ID, order number, shop, source.
loyalty_click Loyalty CTA button CTA text, CTA link, loyalty heading, order context.
referral_click Referral CTA button CTA text, CTA link, referral heading, order context.
faq_click Opening an FAQ answer Question text as CTA text and item title.
video_click Video thumbnail link Video heading, video URL, order context.
recommended_product_click Recommended product image or link Product ID, product title, product URL, CTA text.
